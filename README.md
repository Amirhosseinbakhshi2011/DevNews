# DevNews 📡

سایت جمع‌آوری اخبار و مقالات برنامه‌نویسی از APIهای مختلف.

## منابع

- **Hacker News** (top stories)
- **Dev.to** (articles)
- **Reddit** (r/programming + r/webdev)
- **Lobsters**
- **Hashnode**

## اجرا

```bash
npm install
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) باز می‌شه.

## ویژگی‌ها

- فچ موازی از ۵ منبع
- فیلتر واقعی بر اساس منبع (با URL)
- مرتب‌سازی بر اساس زمان انتشار
- UI مدرن و ریسپانسیو با Tailwind
- پشتیبانی از حالت تاریک
- کش ۵ دقیقه‌ای (ISR)

## تکنولوژی

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- date-fns
